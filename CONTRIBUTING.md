# Contributing to Atom One Pro

First off, thank you for considering contributing to Atom One Pro!

## 🚀 Quick Start for Developers

### Prerequisites

- Rust Toolchain (Stable edition 2021+)
- Obsidian installed locally.

### Local Development Setup

1. Fork and Clone the repository:
   ```bash
   git clone [https://github.com/YOUR-USERNAME/atom-one-pro-obsidian.git](https://github.com/YOUR-USERNAME/atom-one-pro-obsidian.git)
   cd atom-one-pro-obsidian
   ```
